System Files

1. /(root)

- every single file and directory startsfrom root directory

2. /Bin - contain commands

3. /boot

4. /dev - essential device files

5. /etc - et cetera
   -> contains configuration files req by all programs
6. /home - home directory

7. /lib - libraries

8. /media

9. /mnt - temporarily mounted file, only the rooot

10. /opt - optional application software packages

11. /sbin - essential system binaries and only the root is the only one who can use the commands in sbin

12. /tmp - temporary files, both the root and the user can use it

13. /usr - user utilities - used for sharing

14. /var

=> Text editor

- linux command line text editors
  1.  VIM:- very powerful but at the same time it is cryptic and hard to learn
      to enter = i
      to command mode = esc
      to save = :w
      to exit = :q
      to save and exit = :wq!
      to undo = :u

  => visual mode (more for selection)
  types : - character wise -> v in command mode - line wise -> shift + v - block wise -> ctrl + v or ctrl + q
  2.  NANO:-
  - to undo -> alt + u
  - to redo -> alt + r
  - to run -> ctrl + t
  - to save -> ctrl + s
  - too append -> ctrl + r
