-> The difference between cat|less|head|tail

- cat: displays the what's inside on the terminal itself

- head and tail need more than 10 line of data to display

eg: head tell.md ->displays the first 10 in the file

    head -n 15 tell.md -> displays the first 15

    tail tell.md -> displays the last 10 in the file
